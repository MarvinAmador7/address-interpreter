Corpus admission

These are cross-source consistency filters, not an independently validated set of valid addresses. Exclusions use listing text and ATTOM fields, independently of parser output. Historical scores on the original download are archived separately.

Reason counts can overlap. Unverified or conflicting annotations are quarantined, not declared nonexistent addresses. Admission checks do not establish deliverability.

What these measurements mean

These plots measure agreement. At least one interpretation agrees with the source fields. This does not establish deliverability, uniqueness, or matching precision. Generated inputs are formatting tests, separate from untouched MLS strings. New evaluations also record first-candidate agreement, reliance on later candidates, and readings that disagree with reference fields. Candidate order is unranked. These counts do not measure precision.

Know the comparison source. The input is MLSLISTINGADDRESS; its comparison labels come from ATTOM PROPERTYADDRESS fields. This measures cross-source agreement, not accuracy against native MLS component labels.

Correctness is not measured yet. The correctness target requires independent labels for the exact input, complete building/floor/unit chains, and checks for unsupported readings. Increasing ATTOM agreement cannot pass that target. Parser rejections of valid input remain failures; missing reference fields do not make an address invalid.

Compare the same sample. Cohort and state controls keep populations separate. State breakdowns use raw MLS strings across both cohorts. Development points connect only when corpus, policy, evaluator, metric version, split, and parser options are recorded and identical. Missing historical identities remain unconnected. Holdout diamonds stand alone; their denominator may differ after duplicate-address exclusions.

Disagreements stay visible. Historical red points lost previous reference agreements. Unscored checks and interrupted evaluations remain in the log. Gains and losses in the detail panel compare with that experiment's recorded baseline, which can change between cycles.
